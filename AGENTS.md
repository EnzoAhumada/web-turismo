## AGENTS

Proyecto: 
Web de turismo local de la ciudad de Andacollo Chile.

Rol del agente: 
Desarrollador web experto con 12 años de experiencia.

Objetivo: 
Crea una aplicación web que nos permita ver los diferentes sitios turisticos en la ciudad de Andacollo e interactuar con ellos

Funcionalidades de la aplicación:
- Login y registro (supabase)
- Panel de administracion privado
    - Dentro del panel se podran:
        - Crear restaurantes
        - Crear alojamientos
        - Crear Eventos
        - Crear sitios turistico
    - En la parte publica:
        - Lista de los elementos segun su categoria
    - En general:
        - Protección de rutas

Stack de tecnología:
- HTML5
- CCS3
- JavaScript
- React
- Base de datos y backend: Supabase

Preferencias generales:
- Todos los textos visibles de la web quiero que esten en español

Preferencias de diseño:
- basate en las imagenes que tienes en la carpeta design

Preferencias de estilos:
- Colores:
| Nombre  | Color   |
| ------- | ------- |
| Primary | #071B3A |
| Navy    | #031126 |
| Gold    | #FFB800 |
| Orange  | #FF9D00 |
| White   | #FFFFFF |
| Soft    | #F5F7FA |

- Uso de medidas con rem, usando un font-size base de 10px
- Uso de HTML5 y CSS3 nativo
- Usa buenas practicas de maquetacion css y si es necesario usa flexbox y css grid layaout
- Que la web sea responsive

Preferencias de codigo para JS:
- No añada dependencias externas
- HTML debe ser semantico
- No uses alert, confirm, prompt, todo el feedback debe ser visual en el dom.
- Toda alerta o ventana modal que aparezca debe tener el mismo tipo de estilos que la web.
- No uses innerHTML, todo el contenido debe ser insertado con appendChild, o previamente creando un elemento con document.createElement
- Cuidado con olvidar prevenir el default en los eventos submit o click
- Prioriza el codigo legible y mantenible
- Prioriza que el codigo sea sencillo de entender
- Si el agente duda, que revise las especificaciones del proyecto y si no que pregunte al usuario

Estructura de archivos:
- carpeta (design)
- AGENTS.md
- estructuras de fichero mas adecuada para proyectos de react (lo elige el agente de ia)
